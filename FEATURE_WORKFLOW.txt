┌──────────────────────────────────────────────────────────────────────────────┐
│                          COMMON ERROR PATTERNS                               │
└──────────────────────────────────────────────────────────────────────────────┘

ERROR: "No graph loaded. Process an image first."
├─→ CAUSE: You haven't uploaded a P&ID image
└─→ FIX: Go to STEP 4 and upload an image

ERROR: "ModuleNotFoundError: No module named 'openpyxl'"
├─→ CAUSE: Missing Python package
└─→ FIX: pip install openpyxl pandas xlsxwriter

ERROR: "Failed to fetch" or network errors
├─→ CAUSE: Backend not running or proxy issue
└─→ FIX: 
    1. Check backend is running (Terminal 1)
    2. Check http://localhost:8000/health
    3. Restart frontend (Ctrl+C, npm run dev)

ERROR: Features show blank screen
├─→ CAUSE: API endpoint not responding
└─→ FIX:
    1. Check backend console for errors
    2. Check browser console (F12)
    3. Test API: curl http://localhost:8000/health

ERROR: Excel doesn't download
├─→ CAUSE: Missing dependencies or no graph
└─→ FIX:
    1. pip install openpyxl pandas
    2. Upload P&ID first
    3. Check backend console for errors
