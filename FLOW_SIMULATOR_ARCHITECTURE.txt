╔══════════════════════════════════════════════════════════════════════════════╗
║                           DATA FLOW SEQUENCE                                 ║
╚══════════════════════════════════════════════════════════════════════════════╝

1. USER ACTION
   └─> User toggles valve V-102 to CLOSED in Flow Sim tab

2. STATE UPDATE
   └─> closedValves.add("V-102")
   └─> Auto-trigger simulation

3. API REQUEST
   └─> POST /api/simulate-flow
       {
         topology: { nodes: [...], edges: [...] },
         start_node_id: "Tank-101",
         closed_valve_ids: ["V-102"]
       }

4. BACKEND PROCESSING
   └─> Build NetworkX graph
   └─> Run BFS from Tank-101
       • Visit Tank-101 ✓
       • Visit V-101 ✓
       • Visit V-102 ✓ (but mark as blocked)
       • STOP at V-102 (closed valve)
       • Don't visit downstream nodes ✗

5. API RESPONSE
   └─> {
         active_node_ids: ["Tank-101", "V-101", "V-102"],
         active_edge_ids: ["Tank-101-V-101", "V-101-V-102"],
         blocked_nodes: ["V-102"],
         flow_path: ["Tank-101", "V-101", "V-102"],
         total_distance: 250.5,
         message: "Flow blocked by 1 closed valve"
       }

6. GLOBAL STATE UPDATE
   └─> setFlowSimulationResult(response)
   └─> Zustand store updated

7. COMPONENT RE-RENDER
   └─> InteractiveFlowSimulator updates UI
   └─> GraphViewer re-renders with new styles

8. VISUAL FEEDBACK
   └─> Graph Tab shows:
       • Tank-101: 🟢 Green glow
       • V-101: 🟢 Green glow
       • V-102: 🔴 Red glow (blocked)
       • Tank-201: ⚫ Dimmed (not reached)
       • Edge Tank-101→V-101: ═══> Animated green
       • Edge V-101→V-102: ═══> Animated green
       • Edge V-102→Tank-201: ···> Dimmed static

1. Upload P&ID image
2. Go to "Flow Sim" tab
3. Select source node
4. Toggle valves (click to open/close)
5. Switch to "Graph" tab
6. See animated flow visualization!

VISUAL INDICATORS:
🟢 Green glow + animated edges = Active flow
🔴 Red glow = Blocked valve
⚫ Dimmed = Inactive (no flow)
💚 "Flow Simulation Active" badge = Simulation running
