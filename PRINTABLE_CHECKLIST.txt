[ ] Step 1: Open Kaggle
    → Go to: https://www.kaggle.com/code/new
    → Click "New Notebook"
    → Language: Python

[ ] Step 2: Enable GPU Accelerator
    → Click "Settings" (⚙️ icon, top right)
    → Find "Accelerator" section
    → Select "GPU" (P100 or T4)
    → Click "Save"
    → Wait for kernel to restart

[ ] Step 3: Add Dataset
    → Click "+ Add Input" (right panel)
    → Search: "p-and-id-symbols-for-computer-vision"
    → Select by: mollous
    → Click "Add"

[ ] Step 4: Verify GPU is Ready
    Create test cell:
        import torch
        print(torch.cuda.is_available())
        print(torch.cuda.get_device_name(0))
    Result should show: True and GPU name
