┌──────────────────────────────────────────────────────────────────────────────┐
│                          WHAT IS EDAI4?                                      │
└──────────────────────────────────────────────────────────────────────────────┘

EDAI4 (Engineering Document AI - 4th Generation) is an AI-powered platform that
transforms static P&ID drawings into intelligent, queryable digital twins.

PROBLEM IT SOLVES:
├─ Manual P&ID analysis takes 2-3 days
├─ Error-prone tag identification
├─ Time-consuming deliverable generation (4-6 hours)
├─ Manual quality checks
└─ No flow path analysis

EDAI4 SOLUTION:
├─ Automated extraction in 30 seconds
├─ AI-powered tag recognition (88.1% accuracy)
├─ One-click deliverable generation
├─ Automated quality checks (5 seconds)
└─ Digital twin flow simulation

┌──────────────────────────────────────────────────────────────────────────────┐
│                          CORE FEATURES                                       │
└──────────────────────────────────────────────────────────────────────────────┘

1. INTERACTIVE CANVAS VIEWER
   ├─ Technology: React-Konva
   ├─ Pan and zoom on P&ID images
   ├─ Bounding box visualization
   ├─ Hover tooltips
   └─ Click-to-zoom from table

2. SMART DATA TABLE
   ├─ Technology: TanStack Table
   ├─ Sortable and filterable
   ├─ Cross-linked with canvas
   └─ Quick search and filter

3. KNOWLEDGE GRAPH VIEWER
   ├─ Technology: React Flow
   ├─ Physics-based layout
   ├─ Draggable nodes
   ├─ Color-coded by type
   └─ Topology visualization

4. PROFESSIONAL DELIVERABLES ⭐
   ├─ Technology: Pandas + OpenPyXL
   ├─ Instrument Index
   ├─ I/O List (AI/AO/DI/DO)
   ├─ Alarm & Trip List
   └─ Client-ready Excel output

5. DESIGN RULE CHECKER ⭐
   ├─ Technology: NetworkX + Rule Engine
   ├─ 8 automated quality checks
   ├─ Severity levels (Critical/Warning/Info)
   ├─ Detailed recommendations
   └─ Click to view on canvas

6. FLOW PATH SIMULATOR ⭐
   ├─ Technology: NetworkX + BFS Algorithm
   ├─ Upstream/downstream tracing
   ├─ Valve closure simulation
   ├─ Distance calculation
   └─ Impact analysis

7. ENGINEERING COPILOT
   ├─ Technology: Google Gemini + ChromaDB
   ├─ Natural language queries
   ├─ 10 query intents
   ├─ Context-aware responses
   └─ Confidence scores

8. P&ID DIFF ENGINE
   ├─ Technology: Computer Vision
   ├─ Compare two P&ID versions
   ├─ Intelligent matching
   ├─ Change categorization
   └─ Automated redlining

┌──────────────────────────────────────────────────────────────────────────────┐
│                          5-LAYER AI PIPELINE                                 │
└──────────────────────────────────────────────────────────────────────────────┘

LAYER 1: YOLO DETECTION
├─ Technology: Ultralytics YOLOv8
├─ Accuracy: 88.1% mAP50
├─ Detects: Instruments, valves, equipment
└─ Output: Bounding boxes with confidence

LAYER 2: OCR + ISA PARSING
├─ Technology: PaddleOCR + Custom Parser
├─ Extracts: Text from image
├─ Parses: ISA S5.1 tags
└─ Associates: Text with symbols

LAYER 3: GRAPH BUILDING
├─ Technology: NetworkX
├─ Creates: Topology graph
├─ Nodes: Instruments, valves, equipment
└─ Edges: Pipe connections

LAYER 4: SEMANTIC VALIDATION
├─ Technology: Custom Validator
├─ Validates: ISA S5.1 compliance
├─ Checks: Tag format
└─ Identifies: Instrument types

LAYER 5: RAG PIPELINE
├─ Technology: Google Gemini + ChromaDB
├─ Indexes: Graph in vector database
├─ Enables: Natural language queries
└─ Provides: Context-aware answers

┌──────────────────────────────────────────────────────────────────────────────┐
│                          HOW IT WORKS                                        │
└──────────────────────────────────────────────────────────────────────────────┘

STEP 1: UPLOAD P&ID
User uploads P&ID image (JPG, PNG, TIFF)
    ↓
STEP 2: AI PROCESSING (5 Layers)
Layer 1: YOLO detects symbols
Layer 2: OCR extracts text + ISA parsing
Layer 3: Graph builder creates topology
Layer 4: Semantic validation
Layer 5: RAG indexing
    ↓
STEP 3: VISUALIZATION
Frontend displays 5 tabs:
├─ Canvas: Interactive viewer
├─ Graph: Topology visualization
├─ Deliverables: Excel generation
├─ Design Rules: Quality control
└─ Flow Sim: Flow simulation
    ↓
STEP 4: FEATURE USAGE
User interacts with features:
├─ Generate Excel deliverables
├─ Check design rules
├─ Trace flow paths
└─ Ask natural language questions

│                          GETTING STARTED                                     │
└──────────────────────────────────────────────────────────────────────────────┘

PREREQUISITES:
├─ Python 3.8+
├─ Node.js 16+
├─ 8GB RAM (16GB recommended)
└─ GPU optional

INSTALLATION:
1. Clone repository
2. Install backend: pip install -r requirements.txt
3. Install frontend: cd frontend && npm install
4. Configure .env file
5. Download YOLO model

RUNNING:
1. Start backend: python -m uvicorn src.api.main:app --reload --port 8000
2. Start frontend: cd frontend && npm run dev
3. Open browser: http://localhost:3000

QUICK TEST:
1. Upload P&ID image
2. Wait for processing
3. Explore 5 tabs
4. Generate deliverables
5. Check design rules
6. Trace flow paths
