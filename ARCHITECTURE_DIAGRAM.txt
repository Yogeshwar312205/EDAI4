┌──────────────────────────────────────────────────────────────────────────────┐
│                          DATA FLOW                                           │
└──────────────────────────────────────────────────────────────────────────────┘

1. USER UPLOADS P&ID IMAGE
   │
   ▼
2. FRONTEND sends to POST /process
   │
   ▼
3. BACKEND processes through 5 layers
   │
   ├─▶ Layer 1: YOLO detects symbols
   ├─▶ Layer 2: OCR extracts text + ISA parsing
   ├─▶ Layer 3: Graph builder creates topology
   ├─▶ Layer 4: Semantic validation
   └─▶ Layer 5: RAG pipeline indexes
   │
   ▼
4. BACKEND returns ProcessingResult
   │
   ▼
5. FRONTEND displays 5 tabs
   │
   ├─▶ Canvas: Interactive image viewer
   ├─▶ Graph: Topology visualization
   ├─▶ Deliverables: Excel generation ⭐
   ├─▶ Design Rules: Quality control ⭐
   └─▶ Flow Sim: Path analysis ⭐
   │
   ▼
6. USER interacts with features
   │
   ├─▶ Generate Excel → POST /deliverables/generate
   ├─▶ Check Rules → GET /design-rules/check
   └─▶ Trace Flow → POST /flow/trace
   │
   ▼
7. BACKEND processes and returns results
   │
   ▼
8. FRONTEND displays results
